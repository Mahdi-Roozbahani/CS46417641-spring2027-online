1. Barrier intuition
At first there is only the objective f(x) = x². Add x = 3 when you are ready. At the constrained point, the two signed terms in the Lagrangian gradient point in opposite directions and cancel, so ∇L = 0.
unconstrained first
Objective
f(x) = x2
Without a constraint, the minimum is x* = 0.
Constraint
g(x) = x − 3 = 0
When activated, the only feasible x-value is x = 3.
Lagrangian
L(x, λ) = x2 − λ(x − 3)
This is activated only after the constraint is introduced.
KKT stationarity
2x − λ = 0 and x − 3 = 0
Therefore x* = 3 and λ* = 6.
∇f = +6
∇L = ∇f − λ∇g = 0
−λ∇g = −6
Important: the vertical gold line is a physical teaching analogy. Mathematically, the key condition is ∇L = 0: the objective-gradient term and the signed constraint-gradient term cancel at the feasible point.
2. Lagrangian surface after adding x = 3
This panel appears only after the constraint exists. The highlighted point (x*, λ*) = (3, 6) satisfies both components of the Lagrangian gradient, so ∇L(3,6) = (0,0).
waiting for constraint
Add the constraint x = 3The Lagrangian is introduced only after the constraint exists. This keeps the classroom sequence clean: unconstrained objective first, constrained problem second.
Main teaching point: at (x*, λ*) = (3, 6), both partial derivatives vanish: ∂L/∂x = 0 and ∂L/∂λ = 0. Therefore ∇L = (0,0). The full Lagrangian surface is still a saddle, not an ordinary minimum in both variables.
x component of ∇L
∂L/∂x = 2x − λ
At (3,6): 2(3) − 6 = 0.
λ component of ∇L
∂L/∂λ = −(x − 3)
At x = 3: −(3 − 3) = 0.
Gradient at the stationary point
∇L(3,6) = (0, 0)
This is the central stationarity condition you want students to see.
Equivalent balance
∇f = λ∇g
Equivalently, inside ∇L = ∇f − λ∇g, the two signed terms cancel.
