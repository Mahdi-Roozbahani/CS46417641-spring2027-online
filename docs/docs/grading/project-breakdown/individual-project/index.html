Individual Project #

This is your own project (35% of the course grade), not the team project. ML Class Hub supplies the dataset. Follow the fixed report layout and show your own understanding of the work.

  1. Read the individual project requirements for the exact work, undergrad/grad distinctions, checkpoints, and interview expectations.
  2. Use the individual website template as the required page structure. You can preview and download its Markdown starter there.
  3. Register and keep your individual website link in ML Class Hub. Check the course schedule for dates.

Your individual project website and link are separate from your team’s website and link.
