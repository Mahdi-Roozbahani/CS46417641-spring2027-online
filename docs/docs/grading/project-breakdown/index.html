Individual and Team Projects #

These are two separate projects, each with its own website link in ML Class Hub. Keep each link throughout the semester and update the appropriate site at its checkpoints. Dates are on the course schedule; grade weights are in Grading Categories.

Individual project · 35% of the course grade #

Work on your own using the dataset assigned in ML Class Hub. Follow the required analysis and website layout. Start with the Individual Project guide.

Team project · 40% of the course grade #

Work with your registered team on a question and lawful dataset your team chooses. Use one team website from proposal through final. Start with the Team Project guide.

The two websites, submissions, and review requirements are different. Use the guides above to find the instructions for the project you are working on.
