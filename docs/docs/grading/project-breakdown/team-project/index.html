Team Project #

This is the registered team’s project (40% of the course grade), not the individual assignment. Your team chooses a feasible question and lawful dataset and uses one team website for every stage.

  1. Team proposal: introduce the question, data, planned methods, evaluation, and team plan.
  2. Team midterm review and TA meeting: update that same website with work completed, early results, and next steps.
  3. Team final report and TA interview: complete the report and explain the team’s work.
  4. Team website template: use the same core headings at all three stages. Preview or download the Markdown starter here. At final, the team may improve the design and add useful subsections without removing the core headings.

Check the course schedule for dates. Keep the team website link in ML Class Hub; it is separate from each student’s individual link. Every member must understand the whole team project. See the optional team bonus and past awardees for additional information.

See the worked topic and checkpoint example when choosing a question and methods.

Follow the General Course Policies for data use, citations, and AI disclosure.
