Class Resources #

Main Course Reference #

The main reference for this course is Pattern Recognition and Machine Learning (PRML) by Christopher M. Bishop. The course is based primarily on this book, with lecture materials and assigned readings providing additional coverage. A free official PDF is available, so purchasing a printed copy is not required. Complete the readings assigned for each class.

Books and Additional References #

  • Pattern Recognition and Machine Learning (PRML), by Christopher M. Bishop — main course reference; free official PDF.
  • Learning from Data, by Yaser S. Abu-Mostafa, Malik Magdon-Ismail, and Hsuan-Tien Lin — official book website.
  • Machine Learning, by Tom Mitchell — author’s book website and resources.
  • Data Mining: Concepts and Techniques, by Jiawei Han, Micheline Kamber, and Jian Pei — third-edition companion website.
  • The Elements of Statistical Learning, by Trevor Hastie, Robert Tibshirani, and Jerome Friedman — authors’ website with a free PDF.
  • Deep Learning, by Ian Goodfellow, Yoshua Bengio, and Aaron Courville — free online book.

The additional books are supplementary references, not required purchases.

Dataset Ideas #

May need API, or scraping – thanks to Polo and everyone who contributed with suggestions to these datasets:

  • HuggingFace Datasets. [Thanks to Xuhui Zhou] Popular dataset-hosting website for machine learning, especially for natural language processing problems. The unified API is convenient for training models.
  • Google Dataset Search
  • Data Commons
  • Kaggle public datasets
  • Awesome Public Datasets
  • NYC TLC trip records: taxi and for-hire vehicle trip data.
  • Georgia Tech’s campus data (has APIs): campus places and building information.
  • Data.gov: U.S. Government’s open data
  • IPEDS data: Postsecondary education data from National Centre for Education Statistics
  • Bureau of Labor Statistics data
  • Wikidata: structured knowledge with query and download options.
  • Yelp Open Dataset: reviews and business data for educational use; check the dataset terms.
  • OpenAlex: scholarly works, authors, institutions, and citation data.
  • Numerous APIs from Google (e.g., YouTube)
  • Zillow Research housing data.
  • Graph datasets: SNAP.
  • Movies data: IMDb non-commercial datasets.
  • List of lists of datasets for recommendations.
  • Million Song Dataset: audio features and metadata; see the repository for available files.
  • Dataset about soccer games, players, clubs. Check the site’s access and reuse terms before collecting data. For a soccer player: transfer history, performance, nationality, birth date, etc. For a soccer club: performance, squad, etc.
  • Nasdaq Data Link: financial and economic data; availability and access terms vary.
  • UCI Machine Learning Repository: datasets for classification, regression, and other tasks.
  • Amazon AWS Public Data Sets
  • KDD Cup: data-mining competitions.
  • Bibliographic data: DBLP XML downloads.
  • Retrosheet: MLB statistics (Game/Play logs)
  • Classification datasets
  • NOAA NCEI data products: environmental and geophysical data.
  • Pew Research Center datasets.
  • Academic torrents (terabytes)
  • New York Times Article Search API.
  • Case Western Reserve Geotechnical Database.
  • Data Science Initiative – Microsoft Research has various datasets and access to tools that can aid in data science research

Other resources, such as machine learning toolboxes and datasets, will be provided throughout the course.
