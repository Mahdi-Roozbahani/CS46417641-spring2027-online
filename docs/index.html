Machine Learning CS 4641 & 7641 - Spring 2027 - Online

Keep up with course updates #

Course content, requirements, calendar dates, and deadlines on this website may change during the semester. You are responsible for checking this website and the course schedule regularly, reviewing updates, and meeting the current requirements and deadlines.

The teaching team will make every effort to announce important changes on Ed Discussion. Enable Ed notifications and check announcements regularly. Announcements support your own checks; not seeing an announcement does not remove your responsibility to stay informed. See Ed Discussion for communication guidance.

Course Info #

Instructor: Max Mahdi Roozbahani (Machine Learning - CS-7641-A (Spring 27) - Online - Sandbox, Machine Learning - CS-4641-A (Spring 27) - Online - Sandbox)

EdStem: Access through Canvas

Main course reference: Pattern Recognition and Machine Learning (PRML) by Christopher M. Bishop. See course books and the free official PRML PDF.

Course Short Description: This course introduces techniques in machine learning with an emphasis on algorithms and their applications to real-world data. We will investigate the following question: how to computationally extract useful knowledge from data for decision-making and task support! The course will also cover briefly Ethics in Machine Learning and Secure Computing.
