# Optional Team-Project Bonus

The required course components total 100%. A team can earn up to **5 additional course percentage points**, making 105% the maximum possible score. The individual project has no separate bonus. The same five items apply to CS 4641 and CS 7641 teams, but each item must be **additional to the [required work for that course level](../final/)**. A team can earn full required-project credit without any bonus work.

## How to request bonus points

Add an **Optional bonus work** section to the final team website. For each item claimed below, include the requested evidence and name the members who did it. Show the work during the final TA interview if asked. There is no separate upload or deadline. Each completed item earns **+1 course percentage point**; incomplete or unverified items earn **0**. The same data, experiment, visualization, or software feature cannot be counted for two items. At most five points can be earned.

## Five checkable bonus items

1. **Collect new real-world data (+1):** gather observations yourself for this project rather than downloading an existing dataset or creating synthetic, augmented, or AI-generated examples. On the website, state what was observed, how and when it was collected, how many usable observations resulted, and which members collected them. Show a small permitted sample or a collection log. Follow applicable consent, privacy, and data-use rules; do not publish restricted information. Cleaning or augmenting an existing dataset alone does not count.
2. **Test design choices (+1):** run at least two controlled comparisons beyond the required model comparison, changing one choice at a time while keeping the same data split and evaluation measure. For example, test two feature sets and two training-set sizes. Show a table with the choices and results, and explain what each comparison taught you. Merely running more models or listing settings without results does not count.
3. **Test on a second independent dataset (+1):** evaluate a completed method on a second, separately obtained dataset that addresses the same question; a re-split, augmentation, or synthetic copy of the first dataset does not count. State its source and differences from the first dataset, show the result on both datasets using a suitable measure, and explain whether the conclusion changed. The dataset used to claim item 1 cannot also be used to claim this item.
4. **Build an enhanced interactive explanation (+1):** go beyond the required single interactive visualization. Provide at least three meaningful controls (for example, choose a model, choose a feature, and filter a data group) that update actual project data or model results. Show a comparison between at least two methods or groups, explain what readers learn from it, and demonstrate that the controls work. Extra colors, a static plot, or decorative animation do not count.
5. **Build a working model-based tool (+1):** provide a separate usable workflow beyond the report and its visualization. A user must be able to supply a new input, run the team's trained model or method, and see an explained output. Show one example input and output and demonstrate the tool during the final interview. A mockup, static page, or visualization of existing results alone does not count.

Privacy, honest reporting, citations, and disclosure of generative-AI use are required for **every** project; they do not earn bonus points by themselves. [Project awards](../awards-and-examples/) are separate recognition.
