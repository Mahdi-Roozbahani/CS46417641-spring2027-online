# Individual Project

This is **your own project** (35% of the course grade), not the team project. ML Class Hub supplies the dataset. Follow the fixed report layout and show your own understanding of the work.

## Individual project grade breakdown

These are **course percentage points**. The three parts add to the individual project's **35%** of the course grade.

| Individual-project part | Course weight |
|---|---:|
| Midterm website update and 10-minute video | 10% |
| Final TA interview | 15% |
| Completed final project website and results | 10% |
| **Individual project total** | **35%** |

The midterm website update is the work presented in the video, not a fourth graded item. The final interview and completed website are separate graded parts.

1. Read the [individual project requirements](requirements/) for the exact work, undergrad/grad distinctions, checkpoints, and interview expectations.
2. Use the [individual website template](website-template/) as the required page structure. You can preview and download its Markdown starter there.
3. Register and keep your **individual website link** in [ML Class Hub](https://ml-class.cc.gatech.edu/). Check the [course schedule](../../../course-info/course-schedule-mahdi/) for dates.

Your individual project website and link are separate from your team's website and link.
