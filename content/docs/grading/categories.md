# Grading Categories

The required course components total 100%. There is no final exam. Teams can earn up to **5 additional course percentage points** for exceptional optional work beyond the required team project, for a maximum course score of 105%. The [bonus criteria](../project-breakdown/team-project/bonus/) explain what qualifies.

| Component | Course weight |
|---|---:|
| Quizzes 1–14 | 15% |
| Midterm exam | 10% |
| Individual project | 35% |
| Team project | 40% |
| **Total** | **100%** |

Quiz 0 is required preparation but carries no course-grade weight. See [Quizzes and Exams](../qquizzes-and-exams/) for assessment rules and [Project Breakdown](../project-breakdown/) for the two project tracks. Project stages have these course-grade weights:

| Individual project stage | Course weight |
|---|---:|
| Midterm video and website update | 10% |
| Final interview | 15% |
| Final website | 10% |

| Team project stage | Course weight |
|---|---:|
| Proposal | 7% |
| Midterm team interview (no video) | 10% |
| Final team video (one per team; no interview) | 10% |
| Final website and report | 13% |

The individual midterm website update is the work presented in the video, not an additional graded item. The individual final interview and completed website are separate graded components.

For the team final, the video assesses the team's explanation of its work; the website and report provide the full methods, results, and supporting evidence.

Canvas provides the grading entries. The teaching team enters one shared score for a team stage and records an individual score only when a member’s participation warrants a different grade. The Hub remains the place for project work and team coordination.
